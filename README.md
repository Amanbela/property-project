# Indore Property Budget Finder

SEO-focused property intelligence platform for Indore built with Next.js 15, TypeScript, Tailwind CSS, MongoDB Atlas, Mongoose, and Framer Motion.

## Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` (defaults to local MongoDB at `localhost:27017` for testing)
3. Run development server: `npm run dev`
4. Seed data (optional): `npm run seed`

## Features

- Budget recommendation engine with score logic
- Areas listing + dynamic area pages
- Blog listing + dynamic blog articles
- Lead generation form with MongoDB write action
- Admin dashboard shell
- SEO architecture (metadata, sitemap, robots, canonical-ready URLs)
- Mobile-first responsive UI with reusable components
